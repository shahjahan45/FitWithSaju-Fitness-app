# FitWithSaju v25 – Recovery Insights & Smart Training Guidance

FitWithSaju v25 continues directly from v24 Daily Readiness & Recovery.

## New in v25

- 28-day Recovery Insights screen
- readiness trend and check-in consistency
- last 7 days vs previous 7 days comparison
- 28-day vs previous 28-day training-load context
- average sleep, energy, soreness and stress signals
- locally derived recovery observations
- smart, optional session effort/volume guidance
- rest/deload-aware guidance
- Workout integration
- Progress integration
- reduced-motion-safe recovery chart
- new v25 calculation and UI tests

All guidance remains non-medical and user-controlled. No workout is automatically reduced, skipped, cancelled or rescheduled.

See `docs/V25_RECOVERY_INSIGHTS_SMART_GUIDANCE.md` for implementation details.
